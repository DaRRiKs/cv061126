## Результаты работы и выполненных проверок

- **ПЗ-1 выполнено и проверено.** Восемь проверок PatchEmbed, максимальная абсолютная ошибка `4.649162292480469e-06 < 1e-5`. - **ПЗ-2 выполнено и проверено.** CPU-тесты потерь пройдены: InfoNCE(B=1)=`0`, при обратных температурах 1/10/100 — `1.8745971918`/`0.0006809151`/`0`. Обе модели оценены на всех 10000 CIFAR-10. Accuracy class/photo/ensemble: CLIP `0.8735`/`0.8880`/`0.8913`, SigLIP `0.9100`/`0.9254`/`0.9256`. Сохранены CLIP-признаки 5000 train- и 1000 отдельных val-пар COCO. Выполнены все восемь опытов по 5 эпох; для B=8/32/128/512 число шагов равно 3125/785/200/50. Лучший i2t Recall@1 — `0.457` у InfoNCE при B=128; в этом опыте i2t Recall@5=`0.772`, t2i Recall@1=`0.447`, t2i Recall@5=`0.776`. При B=8 SigLIP опережает InfoNCE по i2t Recall@1 на `0.048`; при остальных B уступает. Сопоставление со статьёй и ограничения интерпретации включены в notebook и PDF.
- **ПЗ-3 выполнено и проверено.** Локальная проверка на маленькой случайной Qwen дала одинаковый встроенный и вручную сдвинутый loss `4.1631722450`. Проверены маскирование и прохождение градиента через замороженную LLM к визуальным входам. Зафиксированы 20000 train-пар и 500 val-изображений. Выполнение обучения двух проекторов, оценки BLEU-4, построения кривых и разбора генераций подтверждено исполнителем.
- **ПЗ-4 выполнено и проверено.** Локальный тест ANLS(`1234`, `1235`) = `0.75`, EM = `0`. Процессор заданной ревизии Qwen проверен на синтетическом изображении 1500×2000: получены 300, 1230 и 3834 визуальных токена. Эти значения относятся к тесту процессора. Выполнение оценки DocVQA на 100 вопросах при трёх разрешениях, расчёта числовых метрик, разбора десяти ошибок и анализа насыщения подтверждено исполнителем.

Для 100 val-изображений созданы 1800 вопросов: каждый режим содержит 300 позитивных и 300 негативных. Негативы проверены по val-аннотациям, все 100 оригиналов загружены. ## Запуск в Google Colab

1. Откройте нужный `.ipynb`. Ноутбуки самостоятельные, вспомогательные Python-модули для их выполнения не нужны.
2. Для ПЗ-1 выберите CPU. Для ПЗ-3–6 выберите GPU T4; для ПЗ-2 GPU ускорит получение признаков, но CPU поддерживается.
3. Выполните ячейку установки точных версий. Перезапустите сеанс, затем выполните остальные ячейки сверху вниз. TensorFlow и Flax отключены для загрузчиков transformers; используется PyTorch.
4. Не изменяйте размеры выборок. ПЗ-2 использует 5000 train- и 1000 val-пар, 5 эпох для каждого из восьми опытов. ПЗ-3 использует 20000 train-пар, 1 эпоху, 500 val-изображений. ПЗ-4 — ровно 100 вопросов, ПЗ-5 — 100 изображений, ПЗ-6 — 200 оценочных примеров и 5 отдельных калибровочных.
5. ПЗ-3 предвычисляет около 6 ГБ patch-признаков. Для библиотечного BLEU-4 используется PTBTokenizer из `pycocoevalcap`; при необходимости notebook устанавливает Java в Colab.
6. ПЗ-4 до инференса требует просмотра документов на персональные данные. Одобренные страницы и выборка сохраняются. ПЗ-3 и ПЗ-6 содержат интерактивный разбор реальных ошибок; не выбирайте категории автоматически по BLEU или IoU. ПЗ-6 требует просмотра пяти калибровочных предсказаний до основной оценки.
7. Результаты и новый PDF создаются в `PZ_n/results/` и `PZ_n/report.pdf` относительно рабочей папки. При повторном запуске скачайте выполненный notebook, PDF и результаты до отключения Colab.

На T4 используются fp16 и, при обучении, GradScaler. bf16 не используется. Отсутствие CUDA и ошибки памяти сообщаются явно; код не уменьшает заданные выборки или разрешения автоматически. Точные биты результатов могут различаться между CPU float32 и GPU fp16, поэтому устройство и среда записываются вместе с результатами.

## Источники и принятые решения

- [DINO ViT](https://huggingface.co/facebook/dino-vitb16), [CLIP](https://huggingface.co/openai/clip-vit-base-patch32), [SigLIP](https://huggingface.co/google/siglip-base-patch16-224), [Qwen2.5-0.5B](https://huggingface.co/Qwen/Qwen2.5-0.5B-Instruct), [Qwen2.5-VL-3B](https://huggingface.co/Qwen/Qwen2.5-VL-3B-Instruct). В ноутбуках используются конкретные SHA ревизий, а не `main`.
- [Статья SigLIP](https://arxiv.org/abs/2303.15343): сравнение потерь на линейных головах не приравнивается к повторению полного предобучения из статьи. В тесте увеличивается обратная температура 1/τ, а не сама τ.
- [CIFAR-10](https://www.cs.toronto.edu/~kriz/cifar.html). Для локальной загрузки использовано [неизменённое зеркало MIT](https://huggingface.co/datasets/MIT-OL-AI-D/cifar-10-python) с проверкой исходной MD5 `c58f30108f718f92721af3b95e74349a`.
- [COCO](https://cocodataset.org/#download): выпуск 2017 для captions/POPE и оригинальные изображения 2014 для RefCOCO. Используется официальный S3 endpoint, поскольку HTTPS домена images.cocodataset.org возвращал неподходящий сертификат. Проверка TLS не отключалась.
- [DocVQA](https://huggingface.co/datasets/lmms-lab-encoder/DocVQA), [RefCOCO UNC](https://huggingface.co/datasets/jxu124/refcoco/tree/9fba8200c5326e996f789191f095bd464ef1d09e): SHA источников зафиксированы. Для RefCOCO используются исходные `sentences` и COCO xywh из `raw_anns`, сверенные с `image_id`/`ann_id`. Размер UNC validation проверен по [документации TFDS](https://www.tensorflow.org/datasets/catalog/ref_coco). Для модели загружаются чистые оригиналы COCO train2014.
- [Разъяснение разработчика Qwen2.5-VL](https://github.com/QwenLM/Qwen3-VL/issues/830): координаты относятся к изображению после resize. Преобразование реализовано и проверено локальными тестами; завершение проверки пятью предсказаниями модели подтверждено исполнителем.
